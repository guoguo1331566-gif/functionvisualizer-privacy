一、政策概览

本隐私政策说明 Function Visualizer（以下简称"本应用"）在 iOS、iPadOS 与 macOS 平台上如何处理与您有关的信息。本应用由独立开发者提供，通过 App Store 以付费下载方式分发（定价 4.99 美元，支持 iOS 与 macOS 通用购买）。

本应用的核心功能是在您的设备本地完成数学函数（含显式函数、隐式方程与三维曲面）的解析、计算与绘制。所有计算过程均在本机 CPU/GPU 上完成，不依赖任何远程服务器。

  • 不收集任何数据：我们不收集、不使用、不出售任何可识别个人身份的信息，也不收集设备标识符、位置、通讯录、健康、浏览记录等任何类别数据。
  • 不追踪、不做广告：本应用不包含广告 SDK、归因 SDK 或跨应用/跨网站追踪能力，未声明并使用 App Tracking Transparency（ATT）相关键值。
  • 不联网上传：应用内不存在网络请求代码；macOS 版本在系统沙盒（App Sandbox）中运行且未申请网络客户端权限，操作系统层面即可阻断任何外联。

三、数据在设备上的存储与使用

本应用只在设备本地保存维持正常使用所必需的最少信息，且这些信息不会离开您的设备：

  1. 界面语言偏好：您选择的界面语言记录在系统 UserDefaults 中，用于下次启动时保持一致。
  2. 函数表达式与历史记录：您输入的函数、视角与视图设置保存在本应用的本地存储中，仅用于恢复会话状态。
  3. 导出文件：当您导出图像或数值表时，写入位置完全由您通过系统保存面板（NSSavePanel）或系统分享服务自行选择，应用不会向其他位置写入。

您可以通过删除应用来清除上述全部本地数据；卸载后本应用不会保留任何可恢复的副本，因为不存在任何服务端副本。
